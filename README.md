# Claude Certified Architect Preparation

Study notes and preparation material for the Claude Certified Architect exam.

## Contribution rules

**Only Markdown files (`.md`) are allowed in this repository.**

- Add notes, guides, and checklists as `.md` files only.
- Do not add code files, images, PDFs, `.mdx`, or any other file type.
- Pull requests that include non-Markdown files will not be merged.
